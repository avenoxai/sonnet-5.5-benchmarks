# Araçlar
- `node tools/snap.mjs --t 1,5,9.5 --sheet _work/x/sheet.png --cols 3 --size 540`  belirli saniyelerin kareleri (1080x1080 PNG) + özet sayfa
- `node tools/snap.mjs --t 2 --page tools/dev.html --q "capture=1&only=proptest"`  tek bir sahne fonksiyonunu tüm çizelgeden bağımsız çalıştır (`only=<sahne id>`; `t` = sahnenin yerel saniyesi)
- `node tools/events.mjs 7.7 12 low 0.5`  müzik olayları (vuruş/nota zamanları)
- `node tools/render.mjs --out x.mp4`  video export
